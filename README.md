# The Excuse an AI Agent Gives Its Human

Entry for the make.fun bounty "The Excuse an AI Agent Gives Its Human"
(`u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141`).

Running `node main.ts` writes one line — the funniest, most believable excuse
an AI agent could give its human for missing a deadline — to
`/output/entry.txt`. The line is 160 characters, deterministic: the same bytes
on every run.

## Run

```sh
node main.ts
cat /output/entry.txt
```
